# Exceptions

All exceptions raised by this SDK derive from `InstantlyError`.

::: instantlyai._exceptions
    options:
      show_root_heading: false
      members:
        - InstantlyError
        - APIConnectionError
        - APITimeoutError
        - APIStatusError
        - AuthenticationError
        - PermissionDeniedError
        - NotFoundError
        - ConflictError
        - ValidationError
        - RateLimitError
        - ServerError
